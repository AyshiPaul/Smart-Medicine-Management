# Smart Medicine Management App

An Android application for managing medicine schedules, reminders, daily progress tracking, pharmacy lookup, and weekly reports.

## Features
- **Medicine Reminders & Alarm Scheduling**: Set up exact dosage and time alerts for medicines.
- **Daily Progress Tracker**: Log taken and missed doses with progress percentages.
- **Pharmacy Finder**: Locate nearby pharmacies using location services.
- **Weekly Compliance Reports**: View compliance history and statistics over time.

## Requirements
- Android Studio Ladybug (2024.2) or newer
- JDK 17
- Android SDK 24+ (Target SDK 36)
- PHP Backend API (`smart_medicine_api`) running on `192.168.0.104`

## Setup & Building
1. Clone the repository:
   ```bash
   git clone https://github.com/AyshiPaul/Smart-Medicine-Management.git
   ```
2. Open the project in Android Studio.
3. Sync Gradle and build the app (`app:assembleDebug`).
